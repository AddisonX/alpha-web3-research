# 策略包生成约束

本目录是离线策略交付模板，不是已注册、已部署或收益验证过的交易策略。

- 以宿主项目`src/strategies/base.py`为唯一接口定义，不复制或自创另一套同名类型。
- 默认只修改本目录；需要公共接口、新因子或新数据源时先说明不兼容点，不能越界修改运行系统。
- 保留`strategy.py`及`ImportedLongOnlyStrategy`入口名，使用全新且带版本的策略ID。
- `manifest.json`是供审核的清单，不是宿主已经实现的插件加载或配置系统。
- 不启动Freqtrade、不注册策略、不操作服务器、不修改现有实例和生产模型指针。
- 构造阶段可加载已审核的模型；`decide()`必须没有网络、文件写入、交易库和下单副作用。
- 当前只支持4h完整二元只多目标，至少一币入选；默认执行为每日调仓、最多9仓、1倍杠杆、10%止损。
- 输入是已经收盘bar对应的截面因子，不提供持仓状态或完整OHLCV历史；额外需求明确列出。
- 训练和推理特征顺序、排名、缺失处理必须一致；不得使用未来数据或未收盘bar。
- 包含规则/模型专项测试及宿主信号发布兼容测试；测试不得联网或改动真实运行目录。
- 不交付凭证、数据库、日志、缓存或虚构权重；不把契约测试通过描述成收益验证通过。
