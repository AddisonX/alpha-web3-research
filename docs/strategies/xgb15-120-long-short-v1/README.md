## 研究口径

- 原15个因子，有序名称见同目录manifest；每个因子在固定年度币池内独立做平均秩百分位，之后才剔除因子不完整的预测行。预测资格不使用未来收益。
- XGBoost 3.4.1，120棵树、深度4、学习率0.05，2021年起扩大窗口，年度模型只学习预测年前已实现的超额收益。年度池在1月1日UTC才可知，首个可用北京时间零点为1月2日。
- 北京时间00:00决策，使用刚收盘4小时K线。平台时间戳是这根K线的开始时间，即前一天UTC12:00；信号时刻为UTC16:00。
- 高分端10%做多、低分端10%做空；多空名额分别沿用原十档分组的最后/第一档人数。原持仓留在相应30%范围内则保留，否则由相应10%内未持有的最高/最低分币替换。分数相同时按币名稳定排序。
- 每天重新等权：多头权重之和+50%，空头−50%，总名义敞口100%，1倍杠杆。保留币也调整数量，不是固定数量漂移。
- 收益标签为当日零点至次日零点的币收益，减同年度池当天有完整收益币的均仓收益。手续费配置为每次成交额0.05%；研究净值还存在零延迟价格、缺失结算与事后因子筛选等局限，详见manifest。

## 平台扩展

`StrategyContext`显式允许空头并提供上一轮目标；`StrategyDecision`新增签名权重。校验全部币唯一覆盖、方向与权重一致、两侧各50%且侧内等权。旧策略仍只接受0/1，不能因文件出现负数而自动获得做空权限。

共享信号存储保留正负权重、空头清单；安全校验、审计和独立执行适配器支持空头，并继续拒绝失效信号和实盘资金模式。保留币的调仓目标在每轮固定，订单未成交不重复下单，达到目标后不因日内价格波动持续调仓。

新执行类为`AlphaCrossSectionalLiveLongShortStrategy`，新实例`xgb15-paper`；旧执行类和旧实例不迁移。新配置取消旧9仓上限，以年度截面实际入选数为准。交易所最小下单额、步长、手续费、可用保证金和成交延迟仍可能使实际仓位偏离目标。框架保留−99%紧急止损/强平保护，**不沿用旧策略−10%止损，也不等价于研究中的无止损假设**。实际交易资金费率与滑点未通过本次历史导入验收。
