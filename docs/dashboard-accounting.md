# 实时模拟盘权益口径

适用于多实例 dashboard，不修改 Freqtrade 订单、持仓或策略。

## 资金费用

- 读取 Freqtrade SQLite 的 `trades.funding_fees`，单位 USDT，正数为净收入，负数为净支出。
- `funding_fees` 已包含 `funding_fee_running`，不把二者相加。
- 已平仓使用 `close_profit_abs`，其中已有资金费，不再额外加减。
- 未平仓使用剩余数量的价格盈亏，减去开仓费及预计平仓费，加上尚未归入已实现收益的资金费。
- 部分减仓的 `realized_profit` 计入已实现收益；通过最后一笔已成交退出订单的资金费归入该部分，不重复计入剩余持仓。
- 资金费净收支汇总全部交易的累计资金费，是收益的分项展示，不再次加到权益上。

`权益 = 初始资金 + 已平仓净收益 + 未平仓交易的已实现收益 + 剩余持仓净盈亏`。
资金费已是实际数量对应的 USDT 金额，不再次乘杠杆。
钱包与可用余额沿用 Freqtrade dry-run 的已实现余额口径，不把浮盈视作可用现金。

## 手续费与历史

“交易手续费”沿用交易记录中的开平仓手续费金额汇总，旧 API 字段 `fees` 保留兼容，新增同值字段 `trading_fees`。
持仓净盈亏包含预计平仓手续费，因此不应再从权益扣除页面展示的累计手续费。

更新后新采集的权益点使用上述口径。原有历史快照保留，不凭空重建资金费历史；旧快照未纳入当时持仓资金费时，不能声称整段曲线已追溯修复。
资金费取决于 Freqtrade 的抓取与数据库更新节奏，页面刷新并不等于重新向交易所结算。
本次改动没有增加滑点模型，也不修改历史回测报告。
